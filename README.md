# ☕ Coffee Shop

A modern and responsive coffee shop web application built with **React** and **Vite**.

This project is designed as a modern e-commerce-style coffee shop website with a clean user interface, responsive layout, product browsing, filtering, routing, and client-side state management.

## 🚀 Live Demo

👉 **[View Live Demo](https://coffee-shop-bay-alpha.vercel.app/)**

## 📦 Source Code

👉 **[GitHub Repository](https://github.com/Mohammad2954/coffee-shop)**

---

## ✨ Features

- 📱 Fully responsive design
- ☕ Coffee shop product showcase
- 🛍️ Product browsing and shopping experience
- 🔎 Product filtering and sorting
- 🧭 Client-side routing
- ⚡ Fast and optimized Vite development environment
- 🔄 Server-state management with React Query
- 🗃️ Global state management with Zustand
- 🔔 Toast notifications
- 🎞️ Responsive sliders and carousels
- 🎨 Modern UI built with Tailwind CSS
- 🧩 Component-based architecture

## 🛠️ Technologies

This project is built using the following technologies:

| Technology               | Purpose                                       |
| ------------------------ | --------------------------------------------- |
| **React**                | Building the user interface                   |
| **Vite**                 | Development environment and build tool        |
| **Tailwind CSS**         | Styling and responsive UI                     |
| **React Router**         | Application routing                           |
| **TanStack React Query** | Server-state and asynchronous data management |
| **Zustand**              | Global state management                       |
| **Swiper**               | Sliders and carousels                         |
| **React Hot Toast**      | Notifications                                 |
| **clsx**                 | Conditional class management                  |
| **Oxlint**               | Code linting                                  |

## ⚙️ Installation

First, clone the repository:

```bash
git clone https://github.com/Mohammad2954/coffee-shop.git
```

Navigate to the project directory:

```bash
cd coffee-shop
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

---

## 🏗️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
